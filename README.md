# The Postcode Parliament Pointer

This will let you search a postcode to find the nearest matches based on the latest Ordnance Survey data, and then return details about those postcode's members of parliament.

It combines publicly available data from the UK goverment's [OS Data Hub](https://osdatahub.os.uk/) and from mySociety's [TheyWorkForYou](https://www.theyworkforyou.com/).

## Getting Started

### Dependencies

None.

### Execution

* Run `start.bat`.
* Go to `http://localhost:5173/` in your browser.
